معمارية الشبكة الصارمة

لماذا تفشل الطرفيات الأخرى مع لغة الضاد؟

الطرفيات الكلاسيكية تفترض أن الشاشة مجرد مصفوفة خلايا ثابتة تكتب من اليسار إلى اليمين فقط. عند كتابة جملة عربية داخل Bash أو OpenCode، تنفصل الحروف وتظهر معكوسة، أو ينقلب موجه الأوامر بالكامل.

في Twitty v2، اعتمدنا نظام عزل المقاطع (Scoped RTL) مع شبكة خلايا صارمة (Cell-Locked Grid):

  • موجه أوامر هجين ثابت: الرموز مثل ~ ❯ تبقى ثابتة على اليسار دائماً دون أن يقلبها النص العربي.
  • رسم هندسي مصمت: خطوط الجداول وبلوكات الشعار (█, ▄, │) تُرسم عبر كرت الشاشة بدون أي فجوات خطوط.
  • تخزين مؤقت للسطور (Line Cache): معالجة فورية بمعدل 120 إطاراً في الثانية دون أي استهلاك زائد للمعالج.
البداية السريعة

خطوات التثبيت والتشغيل

تتطلب بيئة Rust الحديثة (1.85+) على نظام Linux أو Windows.

1. استنساخ المستودع (الفرع الأصيل v2)

git clone https://github.com/omarallsharkawy/RTL-Terminal.git -b v2-native
cd RTL-Terminal

2. البناء المحسّن فائق السرعة

cargo build --release

3. تشغيل الطرفية

./target/release/twitty
ملف الإعدادات الدائم

يتم حفظ حجم الخط وتفضيلاتك تلقائياً عند التكبير والتصغير بـ Ctrl + = أو عجلة الماوس داخل: 

~/.config/twitty/config.json
المقارنة المعمارية

Twitty أمام Kitty و Ghostty

درسنا معمارية أحدث الطرفيات مثل Ghostty (المطورة بلغة Zig) و Kitty (المطورة بـ C و Python). كلا الطرفيتين رائدتان في السرعة وبروتوكولات الصور، لكنهما تعجزان عن عرض جملة عربية واحدة منسقة داخل واجهة TUI.

Twitty تسد هذه الفجوة التاريخية مع الحفاظ على الأداء المسرّع بالعتاد، وتضع دعماً كاملاً لميزات الحافظة ومفاتيح APP_CURSOR والتمرير بالماوس.
