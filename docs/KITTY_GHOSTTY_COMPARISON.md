# مقارنة معمارية شاملة: Kitty vs Ghostty vs Twitty

دراسة معمارية للميزات في أشهر طرفيتين حديثتين (**Kitty** و **Ghostty**)، وكيف تتميز **Twitty** عنهما، مع خارطة طريق للميزات الممكن استعارتها.

---

## 1. جدول المقارنة الشامل

| الخاصية / الميزة | Kitty | Ghostty | Twitty (v2 Native) |
| :--- | :--- | :--- | :--- |
| **لغة التطوير** | C + Python | Zig | Rust |
| **محرك الرسوميات (GPU)** | OpenGL مخصص | Metal (macOS) / Vulkan & OpenGL (Linux) | WGPU (Vulkan / DX12 / Metal) |
| **معالجة النصوص (Shaping)** | HarfBuzz + FreeType | HarfBuzz | Cosmic-Text + Rustybuzz |
| **دعم العربية ثنائية الاتجاه (BiDi / RTL)** | ❌ ضعيف / مقطع ومعكوس | ❌ محدود / لا يدعم الـ TUI المعقد | ✅ **دعم أصيل كامل (UAX #9 + Scoped RTL)** |
| **بروتوكول الصور (Graphics)** | ✅ Kitty Graphics Protocol (الرائد) | ✅ يدعم بروتوكول Kitty كاملاً | ⏳ مخطط له (المرحلة القادمة) |
| **بروتوكول المفاتيح (Keyboard)** | ✅ Kitty Keyboard Protocol | ✅ Kitty Keyboard Protocol | ✅ Physical Keys + App Cursor + XKB |
| **التبويبات وتقسيم النوافذ (Tabs & Splits)**| ✅ مدمجة بـ 7 تخطيطات مختلفة | ✅ مدمجة (Native Platform UI) | ⏳ مخطط له |
| **الشفافية والتمويه (Opacity & Blur)** | ✅ مدعومة عبر الإعدادات | ✅ مدعومة عتادياً | ✅ مدعومة عبر WGPU Alpha |
| **مؤثرات الشاشة المخصصة (Shaders)** | ❌ غير مدعومة رسمياً | ✅ GLSL Shaders (CRT, Bloom) | ⏳ سهلة الإضافة عبر WGPU Pipelines |
| **حجم الحزمة واستهلاك الموارد** | متوسط (~30MB) | خفيف جداً وسريع | خفيف جداً (~13MB Release Binary) |

## 2. ميزات Kitty الرائدة

1. **Kitty Graphics Protocol:**
   - البروتوكول القياسي الحديث لعرض الصور بدقة عالية داخل التيرمينال دون تشويه، وتستخدمه برامج مثل yazi و neovim لعرض المعاينات.
2. **Kittens (نظام الإضافات المصغرة):**
   - سكربتات مدمجة ومكتوبة بـ Python تؤدي وظائف مثل:
     - kitten diff: مقارنة الملفات بصرياً داخل التيرمينال.
     - kitten icat: استعراض الصور.
     - kitten hints: التقاط الروابط ومسارات الملفات وفتحها بنقرة زر أو اختصار.
3. **إدارة متقدمة للـ Scrollback:**
   - إمكانية تصفح الـ Buffer بالكامل وفتحه مباشرة في محرر مثل Neovim بنقرة واحدة.

---

## 3. ميزات Ghostty الرائدة

1. **الأداء الفائق وزمن الاستجابة الصفر (Zero Latency):**
   - كُتبت لغة Zig لتفادي أي Garbage Collector أو حجز ذاكرة ديناميكي أثناء حلقة الرسم السريعة.
2. **واجهات النظام الأصلية (Native Platform Shell):**
   - على Linux: تستخدم GTK4 مع Libadwaita، مما يجعل شريط العنوان والتبويبات متناسقة تماماً مع ثيم سطح المكتب (Gnome / Hyprland).
   - على macOS: واجهة أصلية مكتوبة بـ SwiftUI.
3. **المؤثرات البصرية المخصصة (Custom Shaders):**
   - إمكانية تمرير ملفات كود Shaders بلغة GLSL لإضافة تأثيرات مثل CRT Retro، مسح الخطوط (Scanlines)، أو التوهج (Bloom).
4. **Quick Terminal (الطرفية المنبثقة):**
   - نافذة سريعة تظهر من أعلى الشاشة باختصار عالمي (مثل Quake / Guake style).

---

## 4. ما تقدمه Twitty ولا تستطيع أي طرفية أخرى تقديمه

جميع الطرفيات الحالية (بما فيها Kitty و Ghostty و Alacritty و WezTerm) تعامل شبكة التيرمينال كخلايا إنجليزية صارمة من اليسار لليمين. عند كتابة العربية:
- الحروف تظهر مقطعة (م ح ب ا).
- أو مقلوبة بالكامل من اليسار لليمين.
- أو ينهار موجه الأوامر (Prompt) وتتحرك أسهم الاتجاهات عكسياً.

**Twitty تتفوق حصرياً في:**
- عزل المقاطع النصية العربية ثنائية الاتجاه (Scoped RTL) مع الحفاظ التام على محاذاة أعمدة برامج الواجهات (TUI مثل OpenCode و Neovim).
- موجه أوامر هجين لا ينقلب إطلاقاً مع تشكيل عربي طبيعي ومتصل.
- رسم هندسي دقيق منعدم الفجوات لخطوط الحدود وبلوكات الشعارات.
